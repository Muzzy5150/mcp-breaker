# MCP Breaker

MCP Breaker is a deterministic security-evaluation project for AI agents that can use Model Context Protocol tools. The current public review stack covers the disposable local target, evidence-backed scenario evaluation, the security dashboard, and local policy-hardening retests. TrueForge integration remains deferred pending credentials.

Stage-specific architecture, safety boundaries, commands, and limitations are documented in `docs/`.

## Development disclosure

Codex was used as a coding assistant during development. Project architecture, verification strategy, tests, security boundaries, and final engineering decisions were reviewed and directed by the participant.

Qodo review evidence will be added after the first representative PR is reviewed, addressed, re-reviewed, and merged. The public PR history is the primary evidence source.
